# Security Policy

## Supported Versions

We actively support security fixes on the latest version of OwlFlow.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **OwlFlow**, please DO NOT report it as a public issue.

Instead, please send an email to:

📧 **security@divmora.com**

Please include:
- A description of the issue and potential impact
- Steps to reproduce or a proof of concept (PoC)
- Any affected components or connectors

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue promptly before public disclosure.
